# SOS — колега в беда

Паник бутон за таксиметрови шофьори в София. Отделно от BAK.

- **Плаващ червен бутон** над всички приложения. Влачи се. **Задържане 2 сек** = тревога; пак 2 сек = спиране.
- Тревогата стига до всички колеги на линия **в радиус 7 км**.
- При тях: **мигаща червена рамка** по края на екрана (не пречи на докосването), **тих звук** 3× на всеки 20 сек, вибрация
  и малка лента горе: Такси N, номер, модел, фирма, разстояние. **ТРЪГВАМ** = навигация до колегата + той вижда, че идваш. **✕** = скрий.
- В спокойно състояние шофьорът е само „Такси N".
- Не замества 112.

## Вход
Регистрационен номер + парола. Номерът трябва да е в софийския регистър (`plates.json`, обновява се на 1-во и 15-то от `emillion-lab/TAXI`).
Паролата се издава от админа на `https://sos.mihov-emil.workers.dev/admin` — показва се веднъж, пази се само PBKDF2 хеш.
Един номер = едно устройство: нов вход изхвърля старото и то получава известие.
Тревога от номер — най-много веднъж на 10 мин; тревогата изтича сама след 30 мин.

## Части
| Път | Какво |
|---|---|
| `worker/` | Cloudflare Worker `sos` + Durable Object `Hub` (WebSocket хъб с хибернация) |
| `android/` | Kotlin приложение, minSdk 26, само OkHttp |
| `scripts/build_plates.py` | номерата от последната снимка на регистъра |
| `.github/workflows/apk.yml` | строи APK → release `apk-latest` |
| `.github/workflows/deploy.yml` | качва Worker-а (ръчно) |

## Първо пускане
1. В **Settings → Secrets → Actions** на това репо (или org secret):
   - `CLOUDFLARE_API_TOKEN` — права Workers Scripts:Edit
   - `SOS_ADMIN_TOKEN` — дълъг случаен низ, това е входът за админ страницата
2. Actions → **Deploy Worker** → Run. Накрая проверява `/health`.
3. Отвори `/admin`, въведи админ токена, издай парола за своя номер.
4. APK: https://github.com/emillion-lab/SOS/releases/download/apk-latest/SOS.apk
5. В приложението: вход → разреши Локация, Известия, Бутон над приложенията, Батерия → **Включи**.

## Известни ограничения
- Само Android. iPhone не позволява бутон над други приложения.
- APK-то е debug подписано с нов ключ при всеки build → обновяване иска деинсталиране. Поправката е фиксиран ключ в secret.
- След рестарт на телефона приложението се включва ръчно (Android 14 не позволява локация от boot).
- Регистърът е публичен — логинът с номер вдига летвата, паролата е истинската защита.
